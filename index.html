Setup

Install UIS My Work

Pick your computer. You do this once; after that, new versions install by themselves.

  1. 1

    Download the installer

    Download for WindowsUIS-MyWork-LiveUpdates.ps1

    If Chrome asks whether to keep the file, choose Keep. Chrome asks this for every script file.

  2. 2

    Run it once

    Open your Downloads folder, right-click UIS-MyWork-LiveUpdates.ps1 and choose Run with PowerShell. On Windows 11, click Show more options first. It takes about a minute, installs for your Windows user only and needs no admin rights. At the end it copies the extension’s folder path for you.

  3. 3

    Load it in Chrome or Edge

    Open chrome://extensions (Edge: edge://extensions), turn on Developer mode, and remove “UIS Portal – My Work Tracker” if you have an older copy. Click Load unpacked, paste the folder path (Ctrl+V) into the address box and click Select Folder.

    Folder:%LOCALAPPDATA%\UIS\MyWork\extension
  4. 4

    Start

    Sign in to portal.uiscom.com, then click the UIS My Work icon (pin it from the puzzle-piece menu) and choose Open dashboard.

What the installer does

  • Puts the extension in %LOCALAPPDATA%\UIS\MyWork\extension
  • Adds a small updater in %LOCALAPPDATA%\UIS\MyWork\updater and registers it for Chrome and Edge under your Windows user. Only the UIS My Work extension can start it.
  • The updater downloads only from the UIS update server, checks each download’s SHA-256 checksum, and never runs what it downloads.

Turn live updates off

Run the remover the same way. It removes the updater and keeps the extension.

Download the remover
  1. 1

    Download the installer

    Download for MacUIS-MyWork-LiveUpdates.sh

    If Chrome asks whether to keep the file, choose Keep. Chrome asks this for every script file.

  2. 2

    Run it once

    Open Terminal (press ⌘+Space, type Terminal, press Return). Type bash and a space, drag UIS-MyWork-LiveUpdates.sh from your Downloads folder into the Terminal window, and press Return. It takes about a minute, installs for your Mac user only and needs no admin password. At the end it copies the extension’s folder path for you.

  3. 3

    Load it in Chrome or Edge

    Open chrome://extensions (Edge: edge://extensions), turn on Developer mode, and remove “UIS Portal – My Work Tracker” if you have an older copy. Click Load unpacked, press ⌘+⇧+G, paste the folder path (⌘+V), press Return and click Select.

    Folder:~/Library/Application Support/UIS/MyWork/extension
  4. 4

    Start

    Sign in to portal.uiscom.com, then click the UIS My Work icon (pin it from the puzzle-piece menu) and choose Open dashboard.

What the installer does

  • Puts the extension in ~/Library/Application Support/UIS/MyWork/extension
  • Adds a small updater next to it and registers it for Chrome, Edge and Brave under your Mac user. Only the UIS My Work extension can start it.
  • The updater downloads only from the UIS update server, checks each download’s SHA-256 checksum, and never runs what it downloads.

FAQ

Questions

Why Developer mode and “Load unpacked”?

UIS My Work is an internal tool for the UIS team, so it is not in the Chrome Web Store. Chrome loads it from a folder on your computer, and Developer mode is the switch that allows that.

Does it need my portal password?

No. It works on your own signed-in portal tab and stores no passwords. Every action runs as you, so the portal records it as you.

I already have an older version.

Remove the old “UIS Portal – My Work Tracker” card in chrome://extensions, then follow the setup above. Your filters and settings are saved to your profile and come back by themselves.

How do updates arrive?

With live updates on, the extension notices a new version and installs it in a few seconds, waiting until you are not typing or saving. The tab reopens by itself. Without them, it shows a banner with the new zip.

Which browsers and systems?

Chrome and Microsoft Edge on Windows 10 and 11, and on macOS (Brave works on Mac too). On other systems, use the zip.

Something went wrong.

Run the installer again; repeating it is safe. In the extension, the update banner’s Turn on live updates shows whether the updater is installed. Still stuck? Ask your UIS My Work admin.
